# Expense Tracker

A simple command-line Expense Tracker written in Python to manage and track daily expenses.

## Features

- **Add Expense**: Record expenses with date, category, description, and amount.
- **View Expenses**: View all recorded expenses.
- **Total Expenses**: Calculate the sum of all expenses.
- **Filter by Category**: Calculate total expenses spent in a specific category (e.g., Food, Travel, Shopping).
- **Persistent Storage**: Stores expense records in a CSV file (`expenses.csv`).

## Requirements

- Python 3.x

## How to Run

```bash
python expense.py
```
